# 🏢 Sistema de Moradores - CRUD Full Stack

Projeto full stack para gerenciamento de moradores de condomínio. A aplicação permite cadastrar, listar, atualizar e remover moradores, contendo informações como nome, apartamento, tipo de ocupação (proprietário ou inquilino) e foto.

O sistema é dividido em backend (API REST) e frontend (interface web).

---

## 🚀 Tecnologias utilizadas

### Backend
- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- MySQL
- Maven

### Frontend
- Next.js
- React
- TypeScript 

---

## 📌 Funcionalidades

- Cadastro de moradores
- Listagem de moradores
- Visualização de detalhes
- Atualização de dados
- Exclusão de moradores

Cada morador possui:
- Nome
- Apartamento
- Tipo (proprietário ou inquilino)
- Foto
